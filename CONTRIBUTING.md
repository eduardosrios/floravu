# Contributing

Floravu is a proprietary project. Contributions may be reviewed, accepted, modified, or declined at the sole discretion of the repository owner.

## Before Contributing

- Read the [License](LICENSE). This repository does not grant permission to use, copy, modify, distribute, commercialize, or create derivative works without prior written permission.
- Keep all project-facing text in English.
- Do not add generated clutter, temporary files, private notes, prompt files, raw research dumps, or unrelated assets.
- List only people who made direct project contributions.

## Project Direction

This project is an HTML, CSS, and JavaScript website template. Do not introduce React, a database, an admin system, or server-side application code unless the repository owner explicitly changes the scope.

Project changes should prioritize:

- Premium visual quality suitable for a professional gardening and landscaping brand.
- Responsive behavior across desktop, tablet, and mobile.
- Accessible markup and readable content structure.
- Clean, maintainable static front-end assets.
- Performance-conscious images, CSS, and JavaScript.

## Pull Request Guidelines

When submitting a pull request:

- Describe the purpose of the change.
- Keep the change focused.
- Include concise verification notes for visual changes.
- Mention any manual testing performed.
- Avoid unrelated formatting churn.

By submitting a contribution, you agree that the repository owner may use, modify, or reject the contribution under the project's proprietary terms.
